# آوای ارورسرویس — پخش‌کنندهٔ ESP32-C3

پروژهٔ ساده و مستقل پخش صدا برای برد **ESP32-C3 Super Mini** که آواهای تعریف‌شده در پنل
`/admin/service-voices` را از سایت می‌خواند و پخش می‌کند. هیچ واسطه‌ای (بله، تلگرام، ربات و…)
در این نسخه وجود ندارد؛ دستگاه مستقیم به API عمومی سایت وصل می‌شود.

**هر دستگاه فقط آواهای خودش را می‌گیرد.** در پنل اول دستگاه فعال کارگاه را انتخاب می‌کنید،
برای همان دستگاه اکشن و صدا تعریف می‌کنید، سپس **شمارهٔ دستگاه** را در فرمور می‌گذارید.

## چطور به فرم مدیریت صدا وصل می‌شود؟

1. در پنل `/admin/service-voices` از نوار «دستگاه هدف» یک دستگاه فعال کارگاه انتخاب کنید.
2. برای همان دستگاه اکشن بسازید (کلید، نام، تعداد تکرار، اولویت) و صدایش را ضبط کنید.
3. فایل صدا در `wwwroot/uploads/service-voices/` ذخیره می‌شود (فرمت سازگار: **WAV** یا **MP3**).
4. **کد دستگاه** را در فرمور بگذارید: یا `DEVICE_CODE` در `ava_config.h`، یا در پنل تنظیمات
   وای‌فای دستگاه (`AVA-Setup`). این همان `DeviceNumber` است که زیر نوار انتخاب دستگاه در پنل نمایش داده می‌شود.
5. دستگاه هر ۶۰ ثانیه (در حالت بی‌کار) این آدرس را می‌خواند:

```
GET https://errorservice.ir/api/device/service-voices?code=AVA-001
```

نمونهٔ پاسخ:

```json
{
  "deviceNumber": "AVA-001",
  "deviceTitle": "دستگاه کارگاه نمونه",
  "version": 1762600000,
  "count": 2,
  "actions": [
    {
      "id": 3,
      "key": "defrost",
      "titleFa": "دیفراست",
      "repeatCount": 2,
      "priority": 10,
      "audioUrl": "https://errorservice.ir/uploads/service-voices/defrost-....wav",
      "format": "wav",
      "audioSizeBytes": 125000,
      "version": 1762599999
    }
  ]
}
```

فقط اکشن‌های **همان دستگاه**، **فعال** و **دارای فایل صدا** برگردانده می‌شوند و ترتیب پخش
همان `Priority` پنل است (عدد کمتر = زودتر). اگر `code` خالی یا نامعتبر باشد، سرور خطای
`400` یا `404` برمی‌گرداند و دستگاه چیزی پخش نمی‌کند.

## سخت‌افزار

| قطعه | پین ESP32-C3 |
|---|---|
| MAX98357 — BCLK | GPIO5 |
| MAX98357 — LRC (WS) | GPIO4 |
| MAX98357 — DIN | GPIO6 |
| دکمهٔ قبلی | GPIO0 |
| دکمهٔ پخش/توقف | GPIO1 |
| دکمهٔ بعدی | GPIO2 |
| LED وای‌فای | GPIO8 |
| LED وضعیت فهرست | GPIO9 |
| LED پخش | GPIO10 |
| دکمهٔ BOOT (ورود به پنل) | GPIO9 |

- دکمه‌ها با `INPUT_PULLDOWN` خوانده می‌شوند؛ یعنی فشردن = اتصال پین به **3.3V**.
- اگر دکمه‌ها را به GND وصل می‌کنید، در `ava_config.h` مقدار `BTN_ACTIVE_HIGH` را `0` کنید.
- LED ها اکتیو-های فرض شده‌اند؛ برای LED اکتیو-لو `LED_ACTIVE_LOW` را `1` کنید.
- تغذیهٔ MAX98357 را از 5V بدهید و GND مشترک با برد باشد.

### طرز کار دکمه‌ها

| دکمه | در حالت بی‌کار | حین پخش |
|---|---|---|
| پخش (GPIO1) | شروع پخش از آوای انتخاب‌شده تا آخر فهرست | توقف / ادامه |
| بعدی (GPIO2) | انتخاب آوای بعدی | رفتن به آوای بعدی |
| قبلی (GPIO0) | انتخاب آوای قبلی | رفتن به آوای قبلی |

هر آوا به تعداد `RepeatCount` تعریف‌شده در پنل پشت‌سرهم تکرار می‌شود.

## کتابخانه‌ها

- **ESP8266Audio** (2.4.x) — پخش MP3/WAV روی I2S
- **ArduinoJson** (7.x) — خواندن پاسخ API
- هستهٔ **Arduino-ESP32 3.x** (`esp32:esp32:esp32c3`)

`WiFi.h`، `WiFiClientSecure`، `HTTPClient` و `WebServer` داخل خود هسته هستند.

## تنظیمات

همهٔ تنظیمات در `ava_config.h` است:

- `DEVICE_CODE` — **کد/شمارهٔ دستگاه**؛ فقط آواهای همین دستگاه از سرور گرفته می‌شود
- `WIFI_SSID` / `WIFI_PASS` — وای‌فای پیش‌فرض (اگر خالی باشند، پنل تنظیمات بالا می‌آید)
- `SERVER_BASE` — آدرس سایت (`https://errorservice.ir`)
- `VOLUME_GAIN` — بلندی صدا (پیش‌فرض `3.0`)
- `AUTO_PLAY_ON_BOOT` — پخش خودکار همهٔ آواها بعد از اولین دریافت فهرست
- `POLL_INTERVAL_MS` — فاصلهٔ تازه‌سازی فهرست
- پین‌ها و LED ها

## پنل تنظیمات وای‌فای

- اگر وای‌فای یا **کد دستگاه** ذخیره نشده باشد، یا هنگام روشن‌شدن دکمهٔ BOOT را نگه دارید،
  دستگاه شبکهٔ `AVA-Setup` (رمز `12345678`) را بالا می‌آورد.
- آدرس: `http://192.168.4.1`
- در پنل هم وای‌فای و هم **کد دستگاه** را وارد کنید. این کد همان `DeviceNumber` پنل آواهاست.
- اگر اتصال وای‌فای بیش از ۲ دقیقه قطع بماند، دستگاه خودش به پنل برمی‌گردد.
- تنظیمات در حافظهٔ NVS ذخیره می‌شوند و با فلش دوباره پاک نمی‌شوند.

## فرمت صدا — مهم

- دستگاه فقط **MP3** و **WAV** را پخش می‌کند (دیکودر ESP8266Audio).
- فرم ضبط مرورگر (webm/opus) روی ESP32 پخش نمی‌شود؛ به همین دلیل
  `service-voice-recorder.js` صدای ضبط‌شده را قبل از آپلود به
  **WAV 16kHz / mono / PCM16** تبدیل می‌کند.
- اگر فایل MP3 آماده دارید (مثلاً با ffmpeg)، همان را آپلود کنید؛ دستگاه MP3 را هم می‌خواند.

نمونهٔ تبدیل دستی با ffmpeg:

```bash
ffmpeg -i input.webm -ar 16000 -ac 1 -c:a pcm_s16le output.wav
```

## build و آپلود

با Arduino IDE:

1. برد `ESP32C3 Dev Module` را انتخاب کنید (FQBN: `esp32:esp32:esp32c3`).
2. در بخش **Tools → Partition Scheme** گزینهٔ
   **Huge APP (3MB No OTA/1MB SPIFFS)** را انتخاب کنید. فرمور MP3 کمی بزرگ است و
   با پارتیشن پیش‌فرض (۱.۲ مگابایت) تقریباً پر می‌شود.
3. کتابخانه‌های ESP8266Audio و ArduinoJson را نصب کنید.
4. پوشهٔ `ava_ardino` را باز کنید و آپلود بزنید.

با arduino-cli:

```bash
arduino-cli compile --fqbn "esp32:esp32:esp32c3:PartitionScheme=huge_app" ava_ardino
arduino-cli upload  --fqbn "esp32:esp32:esp32c3:PartitionScheme=huge_app" -p COM5 ava_ardino
```

## نکته‌های فنی

- سایت اصلی HTTP را به HTTPS ریدایرکت می‌کند؛ پس کل ارتباط دستگاه TLS است
  (`TLS_INSECURE=1` گواهی را بررسی نمی‌کند تا نیازی به قرار دادن گواهی ریشه نباشد).
- منبع صدا (`AudioFileSourceHTTPSRange`) در صورت قطع اتصال با هدر `Range` از همان بایت ادامه می‌دهد.
- فهرست آواها فقط در حالت بی‌کار تازه می‌شود، پس وسط پخش وقفه‌ای ایجاد نمی‌شود.
- تغییرات پنل حداکثر تا ۶۰ ثانیه بعد (در حالت بی‌کار) روی دستگاه اعمال می‌شود.
- اگر کد دستگاه در `ava_config.h` را عوض کردید ولی قبلاً از پنل ذخیره کرده‌اید، مقدار قدیمی در NVS
  باقی می‌ماند؛ یک‌بار در پنل دستگاه «پاک کردن تنظیمات» را بزنید یا کد جدید را از همان پنل وارد کنید.
